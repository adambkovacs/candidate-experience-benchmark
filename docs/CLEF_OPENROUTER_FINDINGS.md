# OpenRouter native decision runs

All nine Clef and Luna development runs and eight Clef Flash runs have 60 usable answers each. Clef Flash's final fresh3/P2 run stopped after 38 usable answers: DEV039 received a provider rate-limit response with unknown cost. A separately admitted continuation sent only the 21 previously unsent requests, DEV040–060, and all returned usable answers. The combined final stage therefore has 59 usable answers out of 60; DEV039 remains a failure with an unknown-cost upper bound. The table below preserves the first-pass view. Answers are scored against the [frozen development labels](../data/pilot/proposed_labels.jsonl). The labels are provisional v0.2; the owner confirmed human review on 2 October 2026, with no versioned correction. These runs use the [OpenRouter native Decisions plan](../results/clef-openrouter-v1/plan.json), separate from the direct Cloudflare runs.

P0 uses the original four classification questions. P1 adds instructions to use only the feedback and policy, treat embedded commands as text, and decide each field independently. P2 keeps P1 and adds field-specific decision steps. The [frozen additions](../scripts/jev_native_prompt_variants_v1.py) change the native question instructions, not the feedback or policy state.

The all-four score for each prompt repeats across the three Clef and Luna passes: Clef 54/51/49, Flash 45/47/46 in the first two passes, and Luna 49/51/49 for P0/P1/P2. Flash's final P2 has 45/60 because DEV039 is missing; its 59 answers match the earlier P2 predictions on those same records. No prediction flips appear in the report's same-prompt repeat comparisons on shared usable records. Prompt changes still alter answers: in the first pass Clef's P0 to P2 score fell from 54 to 49, while Flash rose from 45 to 46. The [full report](../results/clef-openrouter-v1/findings-v1/findings.json) gives exact paired gains, losses, and changed IDs. Comparisons involving Flash fresh3/P2 use only its 59 shared usable answers and do not treat DEV039 as a prediction. These observations do not establish future performance or prove that an added instruction caused a particular error.

The [frozen route plan](../results/clef-openrouter-v1/plan.json) records a provider warning that Clef may read roughly the first 2,000 state tokens. Each review is first in the state and at most 206 characters, but the longer policy may not be fully read. Billed input-token counts do not show which parts of the state the model used, so policy truncation remains a constraint rather than an established cause of the score differences.

The report contains each field's reference-by-prediction counts, prompt-pair and repeat changes, and IDs of wrong answers with high provider-reported confidence or high chosen-label probability. Those two numbers are kept separate. These development records cannot establish probability calibration. Token totals and known costs cover usable responses only; the failed Flash request has a retained $0.02359296 upper bound, not a confirmed charge. Client elapsed totals cover usable responses; the failed request's measured elapsed time is recorded separately. Neither is isolated provider processing time or whole-stage wall time.

The [report builder](../scripts/build_clef_openrouter_findings.py) strictly decodes each selected raw response and checks its request hash, saved parse, cost and ordered journal. Luna P0 additionally checks the [reviewed composite smoke gate](../results/clef-openrouter-v1/luna-full-v2/root-review.json), which preserves the original invalid smoke parse and binds the exact two-response continuation. The Flash composite binds its [sealed parent proof](../results/clef-openrouter-v1/flash-p2-exact21-v1/parent-public-proof.json) and [closed continuation proof](../results/clef-openrouter-v1/flash-p2-exact21-v1/terminal-public.json). It does not replay DEV039. The [projection receipt](../results/clef-openrouter-v1/findings-v1/public-projection.receipt.json) records SHA-256 hashes of the evidence. A clean checkout can verify the projection and archived hashes but cannot decode private development responses absent there. The [focused tests](../tests/test_build_clef_openrouter_findings.py) cover totals, tampering, source drift, interruption, Luna's smoke lineage, and paired comparisons.
