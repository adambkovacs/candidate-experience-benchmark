# Gemma 26B P2: a stopped run and its separate suffix

The Gemma 26B reasoning-on P2 run stopped at fictional comment DEV-007 when the provider returned HTTP 429. Its original dispatch saved six usable answers and one service error. A separately admitted continuation later sent only DEV-008–DEV-060 and saved 53 usable answers. Across those two dispatches, **59 of the same 60 comments have answers in the required format; one has a provider failure**. This is a descriptive reconstruction of an interrupted condition, not a completed clean matched-three pass or 60 valid responses. The original P2 claim and journal remain stopped; the [continuation journal](../results/repeatability-v1/gemma26-on-fresh-matched3-v2/interruption-continuation-v1/fresh1/P2/suffix.journal.jsonl) closes only the 53-record suffix. The [versioned continuation manifest](../results/repeatability-v1/gemma26-on-fresh-matched3-v2/interruption-continuation-v1/manifest.json) explicitly marks the series ineligible for a clean matched-three claim.

All agreement counts below use the unchanged [AI-authored provisional labels](../data/pilot/proposed_labels.jsonl), scored **after** inference. The comments are fictional, and the labels have not been independently adjudicated by people. A match means agreement with those saved labels, not demonstrated performance with real candidates. ## Recalculation boundary

The offline calculation joins IDs DEV-001–DEV-007 from the sanitized prefix with DEV-008–DEV-060 from the suffix, asserts one row per ID, counts only `status="ok"` predictions as usable, and compares their four fields with `proposed_labels` in the 60-row v0.2 file. A field match and an all-four match each contribute zero for the service-error row. Costs sum non-null `observed_cost_usd` values as decimals; the unknown bound is reported separately. Tokens sum the provider's top-level usage fields without adding nested reasoning counts. Paired comparisons intersect the 59 usable P2 IDs with the corresponding P0/P1 IDs.
