## Smallest admissible smoke

Use the existing input-only **DEV-001, DEV-002, DEV-003** in that order, with the existing policy and four Choice criteria from [`jev_benchmark.py`](../scripts/jev_benchmark.py). Never send reference labels, prior predictions or review metadata. Freeze one configuration per **model + provider + version/revision + interface**, with request bytes, option order, parser, declared control values and route identity saved before dispatch. Preserve each raw response, request timing, usage, response model, probabilities, confidence (when native), and any error or unknown charge. Treat three successes as protocol evidence only, not quality or calibration evidence. A full 60-position pass, and any repeat series, needs a separate admission; the historical roster's [P0/P1/P2 distinction](CURRENT_GOALS.md) remains intact.

The first low-friction smoke would be Liquid d1, then Solar Decide, then Alibaba preview **only after** each account's access and a true zero-cost or bounded-price condition is verified. They can use the same four-question payload, but the current [`jev_benchmark.py`](../scripts/jev_benchmark.py) rejects their origins and model IDs. Its `parse_response` is a useful validation pattern, not proof the endpoints are interchangeable. Add an allowlisted provider-specific transport and cost guard; do not weaken the existing TypeSafe validation. For OpenRouter Kev/Jev, use the native Decisions endpoint and reserve against the shared paid ledger; for Cloudflare, use its native wrapper and separate account control. Tev needs four calls per record and a distinct generated-label parser. Drex and Fastino need exact API identity and pricing (or a separately admitted local protocol) first.
