# Hosted continuation findings, 2026-09-28

The seven [source-bound continuation evaluations](../results/prompt-comparison-v1-2026-09-24/paired-reports/hosted-remaining-audit-v1/continuation-pairs-v1/index.json) show no consistent gain from the longer instructions. P1 improves some serious-concern and testimonial judgments while losing sentiment judgments. P2 makes further changes in both directions. These are descriptive development results, not additions to the strict paired cohort: **all seven reports set `eligible_paired_comparison: false`**.

P0 is the frozen baseline. [P1](../prompts/variants-v1/P1-classifier.txt) adds classifier framing, feedback-only evidence, independent field judgments and an exact-output reminder. [P2](../prompts/variants-v1/P2-classifier-sop.txt) contains P1 verbatim and adds an ordered procedure for usable evidence, sentiment, ordinary follow-up, serious reports, testimonial potential and output checks. The [prompt protocol](PROMPT_VARIANTS.md) defines these as append-only instructions; they do not change the rubric or allowed labels.

## Eligibility boundary

The [remaining-pair audit](HOSTED_REMAINING_PAIR_AUDIT_2026-09-28.md) verified 60 saved positions per condition and found no saved request or adapter-control mismatches. The continuation adapter verifies the raw requests and lifecycle journals, then scores against provisional development references offline. Each report records a later continuation that did not preserve the original counterbalanced condition schedule. The adapter also does not establish semantic smoke/admission review or the original evaluator's historical retry-selection contract. Its explicit `protocol_controls_verified: false` and `eligible_paired_comparison: false` govern publication. These seven results can guide case review and future matched runs; they do **not** increase the strict audited paired count or establish a causal prompt effect.
