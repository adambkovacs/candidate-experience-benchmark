References stay out of requests.

Before freezing a second manifest, the controller requires the exact stopped claim, review, journal, attempts, response and wire hashes; the sealed old-child hash; the exact reconciliation file and matching master event; the six prior completed stages; original plan and controller bindings; and a separately allocated v3 child budget. It also binds the paid adapter, route, v3 budget, partition, prompt diagnostic and their direct Python helpers. Manifest verification checks these files, and the dispatch loop rechecks them before each request reservation. At dispatch it requires a phase-specific root receipt, the original route and controls, an active child with room for a full per-attempt reserve, and an unclaimed output path. The proposed manifest marks `clean_matched_three_eligible=false`. A later report must count `fresh2/P0` as an interrupted original plus a separately admitted 58-comment suffix, never as a clean fresh 60-comment dispatch.
