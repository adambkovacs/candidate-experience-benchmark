The [repeat protocol](REPEATABILITY_PLAN.md) still requires a versioned schedule around the observed P0, P2, P1 order, a fixed seed policy, current route and runtime checks, smoke inspection, and subscription quota admission before launch. This document does not admit or dispatch those runs. If a future run changes a material control that cannot be justified within this declared series, it belongs to a separately declared matched three-pass series.

The [execution manifest](../results/prompt-comparison-v1-2026-09-24/subscription-codex-runtime163-v1/codex-gpt-6-sol-medium-batch10/execution-manifest.json) records the user's accepted patch continuation. The original order was observed, not prospectively balanced.
