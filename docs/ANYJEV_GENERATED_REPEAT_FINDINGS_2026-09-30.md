# AnyJev generated control: first P0, P1 and P2 phases closed

The [frozen fresh plan](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/manifest.json) schedules nine 60-review development phases: three passes each for P0, P1 and P2. The first [P0](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P0/development.completion.json), [P1](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P1/development.completion.json) and [P2](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P2/development.completion.json) phases are closed in this [source-bound report](../public-site/anyjev-generated-repeats.json). The other six full phases have no score in this publication snapshot.

All 120 [P0](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P0/development.raw.jsonl) and [P1](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P1/development.raw.jsonl) raw responses start with a Markdown code fence. In [P2's raw responses](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P2/development.raw.jsonl), the 30 invalid outputs are fenced and the 30 valid outputs begin with a JSON object. Every response in these three phases ended with `stop`. The declared [parser](../scripts/anyjev_generation_control.py) calls `json.loads` on the complete response and does not strip fences or repair text. The saved [P0](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P0/development.records.jsonl), [P1](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P1/development.records.jsonl) and [P2](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P2/development.records.jsonl) records retain those validity outcomes. P0 and P1's zero agreement scores therefore reflect output format failure, while P2 has one all-field match among 30 valid responses. All scores retain the fixed denominator of 60.

The 60 P0 calls recorded **155.92 seconds** of summed client-observed generation time, **94,350 input tokens** and **2,726 output tokens**. P1 recorded **172.90 seconds**, **104,850 input tokens** and **2,734 output tokens**; P2 recorded **263.58 seconds**, **159,150 input tokens** and **2,664 output tokens**. These times include client overhead and are not isolated inference time. Local hardware and electricity cost were not measured; the report leaves dollars unavailable. The frozen request controls include local MPS execution, thinking disabled, sampling disabled and one attempt per review. Reference labels were withheld from inference and used only for offline scoring.

P2's fixed-60 all-field score exceeds P0 by one, but **no review is valid in both phases**. P0/P1 and P0/P2 both have a shared-valid prompt flip denominator of **0**, so classification-change comparisons are unavailable. No prompt condition has two closed full passes yet; repeat flips and three-pass ranges are unavailable. These results cannot establish answer stability or isolate a prompt effect. The [historical generated observations](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/manifest.json) are separate: their P0 prompt bytes had to be reconstructed, so those runs cannot serve as a fresh pass. This generated JSON control is also separate from [AnyJev's native readout](ANYJEV_RAW_REPEAT_FINDINGS_2026-09-28.md) and calibrated [L1](ANYJEV_L1_REPEAT_FINDINGS_2026-09-29.md) and [L2](ANYJEV_L2_REPEAT_FINDINGS_2026-09-29.md) methods. Native raw returned valid classifications on all 60 reviews despite its 0/60 all-field agreement.

The same 60 synthetic reviews recur across planned passes. References are version 0.2, AI reviewed and provisional. The [offline reporter](../scripts/build_anyjev_generated_repeat_findings.py) checks saved admission, smoke, raw, record, journal and completion evidence before adding a closed phase; its feed lists SHA-256 source bindings. The portable check does not decode generated token IDs with the private tokenizer or rehash private model files.
