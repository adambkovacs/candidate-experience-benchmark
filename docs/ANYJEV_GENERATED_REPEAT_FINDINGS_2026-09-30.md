# AnyJev generated control: five closed phases

The [frozen fresh plan](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/manifest.json) schedules nine 60-review development phases: three passes each for P0, P1 and P2. This [source-bound report](../public-site/anyjev-generated-repeats.json) includes [fresh1/P0](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P0/development.completion.json), [fresh1/P1](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P1/development.completion.json), [fresh1/P2](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P2/development.completion.json), [fresh2/P1](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh2/P1/development.completion.json) and [fresh2/P2](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh2/P2/development.completion.json). The other four full phases have no score in this publication snapshot. Fresh2/P0 has closed smoke evidence, but no closed full phase here.

In each [P2 first](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P2/development.raw.jsonl) and [P2 second](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh2/P2/development.raw.jsonl) phase, 30 invalid outputs are fenced and 30 valid outputs begin with a JSON object. The declared [parser](../scripts/anyjev_generation_control.py) calls `json.loads` on the complete response and does not strip fences or repair text. Saved [P0](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P0/development.records.jsonl), [P1 first](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P1/development.records.jsonl), [P1 second](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh2/P1/development.records.jsonl), [P2 first](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh1/P2/development.records.jsonl) and [P2 second](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/fresh2/P2/development.records.jsonl) records retain those validity outcomes. P0 and P1's zero agreement scores reflect output format failure. Each P2 pass has one all-field match among its 30 valid responses. All scores retain the fixed denominator of 60.

P2's two passes had the same 30 valid review IDs, the same 30 invalid IDs and identical four-field predictions on all 30 shared-valid reviews: **0/30 observed classification flips**. Each field also had 0/30 flips. This describes two saved passes, not a completed three-pass series. P1 returned no valid answers in either pass. Its shared-valid denominator is **0**, so its reported zero changed count cannot establish stable classifications. The first-pass P0-to-P1 and P0-to-P2 prompt comparisons likewise have zero shared-valid reviews, even though the fixed-60 P2 all-field score exceeds P0 by one. No prompt condition has three closed full passes yet.

The repeated P2 predictions also repeat the same class pattern. Among 30 valid outputs in each pass, the model marked testimonial potential `yes` 26 times. [The confusion counts](../public-site/anyjev-generated-repeats.json) show 21 of those 26 against provisional `no` references, one against `insufficient_information` and four against `yes`. This helps explain why only eight of 60 testimonial decisions match the references despite 30 valid outputs. The same 60 synthetic reviews recur across passes; references are version 0.2, AI reviewed and provisional. These counts do not establish performance on other reviews.

The first P0 phase recorded **155.92 seconds** of summed client-observed generation time, **94,350 input tokens** and **2,726 output tokens**. P1 recorded **172.90 seconds**, **104,850 input tokens** and **2,734 output tokens** in its first pass, then **179.78 seconds** with the same input and output token totals in its second. P2 recorded **263.58 seconds**, **159,150 input tokens** and **2,664 output tokens** in its first pass, then **278.16 seconds** with the same token totals in its second. These times include client overhead and are not isolated inference time. Local hardware and electricity cost were not measured; the report leaves dollars unavailable. The frozen request controls include local MPS execution, thinking disabled, sampling disabled and one attempt per review. Reference labels were withheld from inference and used only for offline scoring.

The [historical generated observations](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/manifest.json) are separate: their P0 prompt bytes had to be reconstructed, so those runs cannot serve as a fresh pass. This generated JSON control is also separate from [AnyJev's native readout](ANYJEV_RAW_REPEAT_FINDINGS_2026-09-28.md) and calibrated [L1](ANYJEV_L1_REPEAT_FINDINGS_2026-09-29.md) and [L2](ANYJEV_L2_REPEAT_FINDINGS_2026-09-29.md) methods. Native raw returned valid classifications on all 60 reviews despite its 0/60 all-field agreement. The [offline reporter](../scripts/build_anyjev_generated_repeat_findings.py) checks saved admission, smoke, raw, record, journal and completion evidence before adding a closed phase; its feed lists SHA-256 source bindings. The portable check does not decode generated token IDs with the private tokenizer or rehash private model files.
