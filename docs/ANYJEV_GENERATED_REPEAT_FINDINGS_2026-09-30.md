All 360 saved P0 and P1 responses begin with a Markdown code fence and are `invalid_output` under the declared [strict parser](../scripts/anyjev_generation_control.py), which applies `json.loads` to the complete response without stripping fences. In each P2 pass, 30 responses are fenced and invalid; 30 begin with a JSON object and are valid. The raw response, status and prediction for each review recur within its prompt condition across all three passes. These facts come from the saved [raw responses and records](../public-site/anyjev-generated-repeats.json), whose individual SHA-256 paths are bound in the feed. The repeated zero P0 and P1 agreement scores reflect output format failure, not tested classification accuracy on valid answers.

The three-pass all-field score range is **0–0/60** for P0 and P1 and **1–1/60** for P2. P0 and P1 have **zero reviews valid in all three passes**, so classification-change rates are unavailable even though the recorded changed lists are empty. P2 has the same 30 valid review IDs in every pass and **0/30 observed four-field classification changes** across them; each individual field also has 0/30. Its other 30 reviews are excluded from this flip denominator. The fixed-60 P2 score exceeds P0 by one match in each pass, but P0 and P2 have zero shared-valid reviews for a classification-flip comparison. These results describe the repeated saved outputs and do not isolate the effect of a prompt change.

Among P2's 30 valid outputs in each pass, testimonial potential is `yes` 26 times. The [confusion counts](../public-site/anyjev-generated-repeats.json) put 21 of those against provisional `no` references, one against `insufficient_information` and four against `yes`. That class pattern helps explain the 8/60 testimonial agreement despite 30 valid outputs. The references are AI reviewed and provisional; these development reviews do not measure performance on other data.

The table's seconds sum client-observed generation durations and include overhead; they are not isolated inference time. Token totals are recorded local input and output counts. Hardware and electricity cost were not measured, so dollar cost remains unavailable. The frozen control specifies local MPS execution, thinking disabled, sampling disabled and one attempt per review. Reference labels were used only for offline scoring.

[Historical generated observations](../results/repeatability-v1/anyjev-generated-p0p1p2-v1/manifest.json) remain separate because their P0 prompt bytes had to be reconstructed. This generated JSON control is also separate from AnyJev's [native raw readout](ANYJEV_RAW_REPEAT_FINDINGS_2026-09-28.md), [L1](ANYJEV_L1_REPEAT_FINDINGS_2026-09-29.md) and [L2](ANYJEV_L2_REPEAT_FINDINGS_2026-09-29.md) procedures. The native raw readout returned valid classifications for all 60 reviews despite 0/60 all-field agreement. The [offline reporter](../scripts/build_anyjev_generated_repeat_findings.py) validates saved admission, smoke, raw, record, journal and completion evidence for each phase. Its portable check does not decode generated token IDs with the private tokenizer or rehash private model files.
