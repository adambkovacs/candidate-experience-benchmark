In fresh pass 3, Qwen 27B medium matched all four provisional reference decisions for 57 of 60 comments with the base prompt and 56 with classifier instructions. Xhigh matched 58 of 60 with either prompt. The [source-bound report](../public-site/qwen27-second-continuation-findings.json) combines saved outcomes from separate dispatches to account for all 60 comments in each condition. These are completed interrupted runs, not clean uninterrupted passes.

Among the 59 comments with valid responses in both P0 and P1, medium changed two complete four-field answers, DEV-013 and DEV-030. Both went from matching all four provisional references to differing on one field. Xhigh changed one, DEV-028, which also moved from an all-four match to a disagreement. Each P1 also has a valid all-four match for the comment whose P0 request failed. This is why the fixed-60 score change differs from the shared-valid comparison. The observations do not establish that the prompt caused those changes.

The original failed P0 request in each setting retains an unknown-charge upper bound of $0.047001600. That bound is not a reported charge.
