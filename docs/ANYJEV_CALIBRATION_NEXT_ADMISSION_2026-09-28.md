# AnyJev L1 and L2 repeat admission audit, 28 September 2026

The remaining AnyJev calibration scope contains two different experiments. The saved [L1 study](../results/anyjev-cached-l1-cv5-2026-09-24/README.md) fitted temperatures to previously saved L0 scores without a new model call. The saved [L2 study](../results/anyjev-l2-cv5-hf517-v1-2026-09-24/README.md) fitted native heads and made held-out model calls. Neither is an unlabeled, direct P0 readout like [raw](ANYJEV_RAW_NATIVE_P0_REPEAT_ADMISSION_2026-09-28.md) or [L0](ANYJEV_L0_NATIVE_P0_REPEAT_ADMISSION_2026-09-28.md). A repeat plan must name the fitting procedure, training labels, outer folds, and what is being repeated.

The source files are fixed: input-only [DEV-001–060](../data/pilot/inputs.jsonl) SHA-256 `bd79e602f45f6aff78796ebdca4f2d0b1585c48665b6b8a9af1fe0b5e52d2b9e`; six [contrast pairs](../data/pilot/pairs.json) `76d95b62990700a0338dd71e34c4bf7698d727deef69a344783f853f92b606da`; provisional [development references](../data/pilot/proposed_labels.jsonl) `440fa16759473b6d4ff52fe7e7296e5f2dfca0a58f5df26f20aef0daafed1464`. ## Cached-score L1

The [L1 runner](../scripts/anyjev_cached_l1.py) verifies the saved 60-row [L0 score file](../results/anyjev-qwen06-l0-mps-2026-09-23/development.jsonl) `fba96b08c10f8d85b2ab7e510902689dee302369f33e4f91baf152102cb524a1`, input and label hashes, question options, and the pinned AnyJev temperature-scaler source. Fold construction reads IDs and pair membership, not labels. During fitting, each question's temperature uses only that fold's 48 training labels; the 12 test labels enter offline metrics after the fit. The [evaluation](../results/anyjev-cached-l1-cv5-2026-09-24/evaluation.json) `50e3450c484c2e5587b726fea4e79ca31de4149350ea55de92b95bd202218ee2` contains 20 temperatures and 60 out-of-fold calibrated vectors. Temperature scaling preserved every option ranking and all 240 field predictions.

Re-running that frozen cached-score procedure can test offline calibration reproducibility only. It would reuse the same L0 vectors and labels, so three such runs cannot measure native model-call variability. No direct native L1 inference under `anyjev-qwen06-l1` is saved. A direct L1 repeat needs a separate, source-bound native protocol: specify how each fold's calibration scores and fitted artifact are produced, keep the 12 held-out labels out of that fit, then collect raw native held-out decisions with durable per-operation evidence. It must start a distinctly named series unless an exact direct first pass is found. The 48 labels per fit are below the upstream size range noted in the [saved study](../results/anyjev-cached-l1-cv5-2026-09-24/README.md); do not call the resulting artifacts deployment calibrators or substitute a new labeled dataset without a separate declaration.

The smoke spans folds 1, 4, and 5; the full stage reuses its three saved rows and artifacts, fits the remaining two folds, and adds 57 predictions. Its [collection manifest](../results/anyjev-l2-cv5-hf517-v1-2026-09-24/collection-manifest.json) `41d27495291170ddd312e9a3e81a4fc23806b515d2e7879d44d0823620d83ab1` binds all five artifacts and the 60-row [output](../results/anyjev-l2-cv5-hf517-v1-2026-09-24/full.jsonl) `42c5ec0fb172bb33e4cff3b49bd44406332fc1e594cca3bfdc5e6c82dc1ee17e`. The [operation journal](../results/anyjev-l2-cv5-hf517-v1-2026-09-24/full.operations.jsonl) `0af68af4f700b807ead43724a25d36011639e0a5918450e7411d35066e74912e` preserves fit and prediction starts and results. The earlier failed, unadapted smoke remains in its own [directory](../results/anyjev-l2-cv5-2026-09-24/smoke.operations.jsonl); it is not silently repaired.

The successful L2 output is a candidate first pass **only for an exact replay of this staged five-fold procedure**, including fresh head fitting, smoke reuse, adapter, order, and seed. Two additional complete procedures would yield three observed passes per held-out ID. A simple 60-call loop or reuse of the old fitted heads would change the experiment. Each new pass needs its own frozen manifest, exclusive output paths, shared GPU lock, fit and prediction intent journal, raw outputs before projection, three-row smoke inspection, separate full-stage admission, and no automatic replay of uncertain work. Stop and retain numerical failures. The existing [evaluation](../results/anyjev-l2-cv5-hf517-v1-2026-09-24/evaluation.json) reports candidate-head numerical warnings and an ungrouped inner cross-validation inside each 48-record training fold; outer held-out labels remain excluded from fitting, but the inner split can separate contrast pairs. Repeating the same folds and provisional labels measures procedural stability on these records, not independent generalization.

The label boundary is procedural. The L2 controller reads the complete provisional-label file in the worker process, then narrows the dictionary before `fit_fold`; its prompt guard verifies feedback-only native prompts. The cached L1 runner likewise reads labels for fitting and later evaluation. Neither saved implementation provides an OS boundary that prevents its process from reading outer-test labels. Before claiming strict reference isolation for a new live calibration repeat, use a per-fold worker or equivalent boundary that receives only the 48 training labels and input-only test text, while evaluation reads test labels separately after raw output is saved. If the reviewed objective accepts the existing code-enforced boundary instead, state that narrower guarantee in the manifest and report. This audit makes no inference, load, download, or new calibration fit.
