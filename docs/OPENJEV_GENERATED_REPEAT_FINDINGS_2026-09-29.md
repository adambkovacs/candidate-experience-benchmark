# OpenJev generated repeat: first fresh P0 pass

The [fresh v2 plan](../results/repeatability-v1/openjev-generated-fresh-v2/manifest.json) schedules separate generated-off and generated-on P0/P1/P2 triplets. Only generated-off fresh1/P0 has a closed development stage. The [source-bound report](../public-site/openjev-generated-repeats.json) verifies its three-review smoke inspection, stage receipts and [60-review completion](../results/repeatability-v1/openjev-generated-fresh-v2/generated-off/fresh1/P0/development.completion.json). Historical generated observations are excluded from these fresh passes. The unexecuted v1 plan had a wire-body hash defect; this v2 pass uses the frozen composed request bytes.

The pass saved **60/60** responses. Fifty-three were valid predictions and seven were `invalid_output`: DEV-001, DEV-012, DEV-017, DEV-018, DEV-028, DEV-029 and DEV-058. Each of those seven returned a `stop` finish reason but message content that did not parse as JSON. They remain in the fixed denominator. All four fields matched the provisional reference on **48/60** reviews; individual field agreement was 52/60 sentiment, 52/60 follow-up, 52/60 serious concern and 51/60 testimonial potential. Counting only the 53 valid outputs would change the question being measured.

Among valid outputs, one insufficient-information sentiment reference was marked neutral, one follow-up-yes reference was marked no, and one insufficient-information serious-concern reference was marked yes. Two testimonial-yes references were marked no. The other valid decisions matched the provisional labels. These labels were AI reviewed, not independently adjudicated human ground truth. No second pass or P1/P2 development stage has closed, so there is no within-mode flip estimate or matched prompt comparison. Generated-on remains **0/9** closed phases. The completed native fixed, adaptive and thinking P0 triplets are separate configurations and do not fill generated phases.

The 60 client HTTP requests took **476.18 seconds** in total. Returned usage reports 100,168 input and 2,172 output tokens. These are observed request times and reported tokens, not isolated inference time. Model loading was not included in that request sum, and attributable local cost was not measured. The frozen manifest records configured runtime and asset hashes; its requested reasoning setting is not proof of effective reasoning in the loaded model.
