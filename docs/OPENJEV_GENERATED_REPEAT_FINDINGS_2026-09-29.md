# OpenJev generated repeat: first fresh P0/P1/P2 pass

The [fresh v2 plan](../results/repeatability-v1/openjev-generated-fresh-v2/manifest.json) schedules separate generated-off and generated-on P0/P1/P2 triplets. Generated-off fresh1/P0, P1 and P2 now have closed development stages. The [source-bound report](../public-site/openjev-generated-repeats.json) verifies their smoke inspections, stage receipts and 60-review completions for [P0](../results/repeatability-v1/openjev-generated-fresh-v2/generated-off/fresh1/P0/development.completion.json), [P1](../results/repeatability-v1/openjev-generated-fresh-v2/generated-off/fresh1/P1/development.completion.json) and [P2](../results/repeatability-v1/openjev-generated-fresh-v2/generated-off/fresh1/P2/development.completion.json). Historical generated observations are excluded from these fresh passes. The unexecuted v1 plan had a wire-body hash defect; v2 uses the frozen composed request bytes.

Each phase saved **60/60** responses. P0 and P1 each had 53 valid predictions and seven `invalid_output` results; P2 had 56 valid and four invalid. P0's invalid IDs were DEV-001, DEV-012, DEV-017, DEV-018, DEV-028, DEV-029 and DEV-058; P1's were DEV-004, DEV-009, DEV-024, DEV-040, DEV-043, DEV-048 and DEV-056; P2's were DEV-006, DEV-010, DEV-029 and DEV-044. All returned a `stop` finish reason. P0/P1 invalid messages did not parse as JSON. In P2, two were non-JSON, one had an out-of-vocabulary sentiment value, and one misspelled the follow-up key. Every invalid position remains in the fixed denominator; counting only valid outputs would change the question being measured.

P0 and P1 matched all four provisional reference fields on **48/60** reviews; P2 matched **51/60**. Field agreement for sentiment/follow-up/serious concern/testimonial was 52/52/52/51 for P0, 51/52/51/53 for P1, and 55/55/55/54 for P2, each out of 60. Invalid positions account for part of these differences. P0 and P1 have 46 shared-valid reviews, with three changed four-field answers: one serious-concern and two testimonial decisions. P0 and P2 have 50 shared-valid reviews and two changed serious-concern decisions. P1 and P2 have 49 shared-valid reviews and five changed four-field answers: one sentiment, two serious-concern and two testimonial decisions. Follow-up predictions did not change in any pair's shared-valid set. These paired prediction counts and the fixed-60 accuracy scores answer different questions.

Among P0's valid outputs, one insufficient-information sentiment reference was marked neutral, one follow-up-yes reference was marked no, one insufficient-information serious-concern reference was marked yes, and two testimonial-yes references were marked no. Among P1's valid outputs, two sentiment, one follow-up and two serious-concern decisions missed the reference; all valid testimonial decisions matched it. Among P2's valid outputs, one insufficient-information sentiment case was marked neutral, one follow-up-yes case was marked no, one insufficient-information serious-concern case was marked no, and one reference-negative and one reference-positive testimonial case were reversed. These are provisional AI-reviewed labels, not independently adjudicated human ground truth. P0/P1/P2 are same-pass prompt variants, not a repeat-stability estimate. Generated-off is **3/9** and generated-on **0/9** closed phases. The completed native fixed, adaptive and thinking P0 triplets are separate configurations and do not fill generated phases.

The 60 client HTTP requests took **476.18**, **482.92** and **689.61 seconds** for P0/P1/P2. Returned usage reports 100,168/110,968/166,828 input and 2,172/2,645/2,764 output tokens. These are observed request times and reported tokens, not isolated inference time. Model loading was not included in those request sums, and attributable local cost was not measured. The frozen manifest records configured runtime and asset hashes; its requested reasoning setting is not proof of effective reasoning in the loaded model.
