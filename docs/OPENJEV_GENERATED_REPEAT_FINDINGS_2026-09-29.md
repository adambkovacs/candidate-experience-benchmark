# OpenJev generated repeat: first fresh P0 and P1 phases

The [fresh v2 plan](../results/repeatability-v1/openjev-generated-fresh-v2/manifest.json) schedules separate generated-off and generated-on P0/P1/P2 triplets. Generated-off fresh1/P0 and fresh1/P1 have closed development stages. The [source-bound report](../public-site/openjev-generated-repeats.json) verifies their smoke inspections, stage receipts and 60-review completions for [P0](../results/repeatability-v1/openjev-generated-fresh-v2/generated-off/fresh1/P0/development.completion.json) and [P1](../results/repeatability-v1/openjev-generated-fresh-v2/generated-off/fresh1/P1/development.completion.json). P2's smoke is closed, but its development is not. Historical generated observations are excluded from these fresh passes. The unexecuted v1 plan had a wire-body hash defect; v2 uses the frozen composed request bytes.

P0 saved **60/60** responses. Fifty-three were valid predictions and seven were `invalid_output`: DEV-001, DEV-012, DEV-017, DEV-018, DEV-028, DEV-029 and DEV-058. P1 also saved 60 responses, with 53 valid and seven invalid: DEV-004, DEV-009, DEV-024, DEV-040, DEV-043, DEV-048 and DEV-056. Every invalid response in both phases returned a `stop` finish reason but message content that did not parse as JSON. They remain in the fixed denominator; counting only valid outputs would change the question being measured.

Both phases matched all four provisional reference fields on **48/60** reviews. P0 field agreement was 52/60 sentiment, 52/60 follow-up, 52/60 serious concern and 51/60 testimonial potential. P1 field agreement was 51/60, 52/60, 51/60 and 53/60, respectively. The invalid ID sets do not overlap. Among the 46 reviews valid in both phases, three changed at least one answer: DEV-006 changed serious-concern classification, and DEV-010 and DEV-053 changed testimonial classification. Sentiment and follow-up predictions did not change on those shared-valid reviews. Equal 48/60 scores therefore do not mean the same reviews or predictions were correct.

Among P0's valid outputs, one insufficient-information sentiment reference was marked neutral, one follow-up-yes reference was marked no, one insufficient-information serious-concern reference was marked yes, and two testimonial-yes references were marked no. Among P1's valid outputs, two sentiment cases, one follow-up case and two serious-concern cases missed the provisional reference; all valid testimonial decisions matched it. These labels were AI reviewed, not independently adjudicated human ground truth. P0-to-P1 is a same-pass prompt comparison with only 46 shared-valid reviews, not a repeat-stability estimate. Neither prompt has a second completed pass. Generated-off is **2/9** and generated-on **0/9** closed phases. The completed native fixed, adaptive and thinking P0 triplets are separate configurations and do not fill generated phases.

The 60 client HTTP requests took **476.18 seconds** for P0 and **482.92 seconds** for P1. Returned usage reports 100,168/110,968 input and 2,172/2,645 output tokens, respectively. These are observed request times and reported tokens, not isolated inference time. Model loading was not included in those request sums, and attributable local cost was not measured. The frozen manifest records configured runtime and asset hashes; its requested reasoning setting is not proof of effective reasoning in the loaded model.
