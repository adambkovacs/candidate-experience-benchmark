The two models disagree on the four-field prediction vector for 12 records. Both agree with the key on all four fields for 43 records; Clef alone does so for 10, Flash alone for 2, and neither for 5. The [JSON report](../public-site/clef-findings.json) includes every disagreement ID, per-field confusion matrix, and high-confidence error ID. These paired counts describe this pass only. The two predictions for a given review are paired observations, not two independent reviews.

Both models returned a native probability distribution for every field. The report calculates multiclass Brier score and negative log probability for the reference class from those complete distributions. Its five-bin reliability table compares the probability assigned to the **returned choice** with that choice's observed agreement; the resulting ECE is descriptive with only 60 records per field. The separate provider `confidence` value is **not** treated as the returned choice's probability. At the inclusive 0.8 threshold, Clef has 3 vendor-confidence errors across the four fields versus 5 chosen-probability errors; Flash has 2 versus 4. The report keeps their per-field cases separate, and does not assign calibration semantics to the vendor field.
