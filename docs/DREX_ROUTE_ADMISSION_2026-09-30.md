# Drex route admission check, 30 September 2026

**Status:** Drex remains in the requested decision-model scope. Nace now publishes a numeric Drex API tariff and a conditional free-credit offer, but the inspected public pages do not establish a callable **Drex 1.5** model ID, full request/response contract, or this account's access. This was a read-only review of public pages. No account was created or used; no credential, playground inference, API inference, download, payment, or reservation was involved. The [current goal](APP_GOAL.md) requires exact identity, interface, availability, context, and price checks before a guarded three-record smoke.

## What Nace publishes

| Question | Public evidence and limit |
| --- | --- |
| Which model and context? | [Nace's Drex product page](https://www.nace.ai/drex) names **Drex 1.5**, advertises up to **128K tokens** of context, and distinguishes prior Drex 1.1 at **32K**. It describes choice, yes/no, and score questions, including several questions about one state and a probability for each supplied option. This is product-level evidence, not a machine-readable hosted model ID or a token-count preflight contract. |
| Is there an API? | The [launch article](https://www.nace.ai/blog/introducing-drex) says users can create a free API key; the [Service Terms](https://drex.nace.ai/terms) govern a decision-model API and dashboard, and the [Privacy Notice](https://drex.nace.ai/privacy) describes request, usage, and billing records. The public [sign-in page](https://drex.nace.ai/login) displays `POST /v1/systemone` and `drex-v1.0` in an animated example. That display does **not** establish an API origin, documented request fields, or that `drex-v1.0` invokes the product page's Drex 1.5. No POST was sent. |
| What is the published tariff? | The [Drex Service Terms, §3](https://drex.nace.ai/terms) state prepaid **$0.04 per million input tokens**, free output tokens, and a usage/cost report on each successful response. They say failed requests, including validation, rate-limit and capacity failures, are not charged. Tax can apply. The terms say prices may change with at least 30 days' notice, so verify the account's current rate before admission. This is a published rate, not proof of this account's balance or entitlement. |
| Is there free API credit? | The [same terms](https://drex.nace.ai/terms) say new accounts currently receive a **one-time $25 credit expiring 30 days after sign-up**, and Nace may change or end it. The terms limit it to one free credit per person. The product page's “free to try, no card needed” describes an entry path; neither statement proves that this user has an account, eligible credit, or enough unexpired balance. No signup or top-up is authorized by this review. |
| What operational limits apply? | The [terms, §5](https://drex.nace.ai/terms) describe per-minute and concurrent limits, with higher limits after purchased credit; over-limit requests may return `429` or `529` and `retry-after`. They give no numeric per-account limit. The [Privacy Notice](https://drex.nace.ai/privacy) says the service logs request content for up to 30 days and does not use it for model training. The 60 development feedback texts are synthetic, but this retention still belongs in route review. |

The published `128K` context and $0.04/M input tariff can support a later conservative bound only after the precise hosted token limit, token accounting, model version, and account rate are confirmed. Do not treat “128K” as an exact 128,000 or 131,072 token API ceiling or assume a successful call's reported token count is available before dispatch. Output is stated free, but unknown-cost or ambiguous requests still need a retained reservation under the project's fail-closed budget process.

**Admission blocker:** Nace's public product and sign-in pages do not connect Drex 1.5 to a reproducible API model ID and complete request/response schema. The sign-in animation's `drex-v1.0` must remain separate from the product's Drex 1.5 until Nace documents the relationship. The terms resolve the earlier missing numeric tariff, but account availability, exact context/token accounting, numeric rate limits, and free-credit eligibility remain unverified.
