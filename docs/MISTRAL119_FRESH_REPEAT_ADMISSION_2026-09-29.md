# Mistral Small 4 119B offline fresh-repeat admission

Six input-only plans are frozen for two distinct hosted configurations: `openrouter-paid-mistral-small4-119b-none` and `openrouter-paid-mistral-small4-119b-high`. Each has three new passes with condition orders P0/P1/P2, P1/P2/P0, and P2/P0/P1. Each condition schedules three smoke requests and 60 development requests on the same 60 feedback IDs. This is **offline preparation only**. No new provider call, key read, budget allocation, or development result was made, and no whole-series child cap is proposed.

The [planner](../scripts/mistral119_fresh_repeat_study.py) reconstructs the exact saved P0 DEV-001 request separately for each effort from the locally retained original `results/openrouter-partition-mistral119-{none,high}-2026-09-23/smoke.jsonl` records. Those private originals are hash-bound in the manifests. The [public run registry](../results/openrouter-paid-run-registry.json) and [failed smoke inspections](../results/mistral119-recovery-prep-v2/none-smoke-inspection.json) retain the incomplete-run status. All five none and three high historical DEV-001 smokes remain HTTP 429 failures with no observed charge or model output; they are not pass one of either new series. The [readiness audit](MISTRAL119_REPEAT_READINESS_2026-09-29.md) explains why catalog status alone did not establish serving capacity.

The route and request controls are fixed to `mistralai/mistral-small-2603`, Mistral `mistral/zdr`, quantization reported as `unknown`, 262,144 context tokens, temperature 0, 4,096 output tokens, strict JSON schema, no streaming or provider fallback, and exact reasoning effort `none` or `high`. The saved provider price guard is $0.15/M input and $0.60/M output. P0 uses the original system instruction unchanged. P1 and P2 append the [frozen variant bundle](../prompts/variants-v1/manifest.json) through the [composition helper](../scripts/frozen_prompt_variants.py), retaining the original role, schema, feedback-only user message, and provider settings. The plan binds the input, prompt bundle, schema, original failures, route audit, planner, test, and adapter source hashes. It reads no reference labels or earlier predictions into the requests. No explicit seed was present in the original request; requested and effective seed remain unavailable.

The [paid runner's reservation formula](../scripts/openrouter_paid_benchmark.py) gives $0.04177920 per call at full context and output limits. One three-call smoke needs up to $0.12533760 in reservations before settlement. A full new series schedules 567 calls per effort; all 567 reserved at their maximum would total $23.68880640 per effort. That is a stress bound, not a cost forecast. Since the only historical Mistral119 calls failed before producing usage, `historical_known_cost_proxy_usd` and `whole_series_child_cap_proposed_usd` are null in every manifest. Each old failure's $0.04177920 unknown bound remains separate from observed spending. Future known charges could free capacity as they settle; another unknown would retain its full bound. Neither outcome is assumed in these plans.
