# AnyJev L0: repeatable answers, weak four-field agreement

The native AnyJev L0 configuration returned the same four-field classifications on all 60 fictional development reviews in three separate P0 passes. Every pass had 60 valid outputs, and no field prediction changed between passes. Yet only **4/60** reviews matched all four provisional reference fields in each pass. Stability describes this readout on these reviews; it does not establish correct classification. The 180 outputs are repeated measurements of the same 60 reviews, not independent cases.

| Field | Matches in each pass | Class-level pattern in each pass |
| --- | ---: | --- |
| Sentiment | 37/60 | Negative matches 23/31 reference-negative reviews; positive matches 10/11 reference-positive reviews. Mixed and neutral each match 2/8. The model never predicts `insufficient_information`, which appears twice in the references. |
| Follow-up needed | 13/60 | The model predicts `insufficient_information` 44 times, though the references use it once. Those 44 include 24/35 reference-yes reviews and 19/24 reference-no reviews. |
| Serious concern reported | 34/60 | The model predicts `no` 47 times. It misses 16/25 reference-yes concerns as `no` and predicts `no` for all six reference-insufficient reviews. |
| Testimonial potential | 44/60 | All nine reference-yes reviews are predicted `yes`, but 15/50 reference-no reviews are also predicted `yes`. The one reference-insufficient review is predicted `yes`. |
| All four together | 4/60 | The follow-up field accounts for many joint misses. |

The [source-bound report builder](../scripts/build_anyjev_l0_repeat_findings.py) rechecked the frozen [manifest](../results/repeatability-v1/anyjev-l0-p0-v1/manifest.json), the [original development records](../results/anyjev-qwen06-l0-mps-2026-09-23/development.jsonl), and the [repeat-two](../results/repeatability-v1/anyjev-l0-p0-v1/repeat2/P0/development.records.jsonl) and [repeat-three](../results/repeatability-v1/anyjev-l0-p0-v1/repeat3/P0/development.records.jsonl) stage evidence. The three passes each score 37 sentiment, 13 follow-up, 34 serious concern and 44 testimonial matches. Every pairwise comparison has 60 shared-valid reviews and zero flips, including the full four-field vector. There are no invalid or missing outputs in these closed passes. Scores use [provisional v0.2 references](../data/pilot/proposed_labels.jsonl), which are AI-reviewed judgments rather than independent human adjudication.

The separate [raw native study](ANYJEV_RAW_REPEAT_FINDINGS_2026-09-28.md) also found no flips across its three passes, but matched all four reference fields for 0/60 reviews per pass. Raw per-field agreement was 8 sentiment, 35 follow-up, 25 serious concern and 33 testimonial. L0 adds a content-free prior and scores cyclic option shifts with 14 real prompts and 42 probes per review. Raw uses four question prompts without that prior. L0 has higher agreement on sentiment, serious concern and testimonial, while follow-up falls from 35 to 13. Because the procedures differ in more than one way, these score differences cannot be assigned to the prior alone. Neither native readout has a generative P1 or P2 prompt condition. The [L0 admission note](ANYJEV_L0_NATIVE_P0_REPEAT_ADMISSION_2026-09-28.md) and [raw admission note](ANYJEV_RAW_NATIVE_P0_REPEAT_ADMISSION_2026-09-28.md) specify their controls.

Recorded request durations total 2,903, 5,289 and 3,701 seconds across the original, second and third passes. These include client and local runtime overhead. The historical session also had background artifact downloads, so the totals are not matched measures of model inference speed. Each pass records 5,070,194 input-token positions across the native prompts; these are not billed API tokens. Output-token counts, isolated inference time, and local hardware and electricity costs are unavailable, not zero. Historical prompt bytes were reconstructed from pinned source and tokenizer rather than saved as prompt hashes, as documented in the [admission note](ANYJEV_L0_NATIVE_P0_REPEAT_ADMISSION_2026-09-28.md).
