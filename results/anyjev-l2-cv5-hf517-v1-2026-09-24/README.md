# AnyJev native L2, five held-out folds

This separate configuration ran the pinned AnyJev L2 `Decider.fit_head` and `decide_batch` interface on Qwen3-0.6B. The [protocol](../anyjev-l2-protocol-2026-09-24/protocol-v3.json), [run manifest](../anyjev-l2-protocol-2026-09-24/run-manifest-v2.json), [Transformers 5.17 adapter](../../scripts/anyjev_hf_517_adapter.py), and [root smoke](../anyjev-l2-protocol-2026-09-24/root-approved-smoke-review-v2.json) and [full](root-full-review-v1.json) review receipts bind the run. The first, unadapted smoke [stopped before a fit or prediction completed](../anyjev-l2-cv5-2026-09-24/smoke.operations.jsonl); its evidence was retained. The corrected run used a new output directory and did not replay that attempt silently.

The [full output](full.jsonl) has one out-of-fold prediction for each DEV-001–060 record. The [operation journals](smoke.operations.jsonl) and [full-stage journal](full.operations.jsonl) show 12 fitted heads for the three-fold smoke, eight further fitted heads for the remaining two folds, and 240 four-question prediction calls in total. The full stage reused the three byte-matching [smoke rows](smoke.jsonl) and their fold 1, 4, and 5 artifacts, then saved 57 new records. The [collection manifest](collection-manifest.json) binds all five fold artifacts. Each fold held out 12 records and trained on the other 48 provisional labels; all six contrast pairs remained together. Outer-fold test labels did not enter fitting or model prompts. Recorded prompt audits used feedback-only states, marked reference labels absent, and reached at most 1,559 of the 4,096 context tokens.

The [offline evaluation](evaluation.json) uses the AI-reviewed provisional development references only after inference. It reuses the fixed [L1 metric definitions and implementation](../../scripts/anyjev_cached_l1.py): mean negative log probability of the true class, multiclass Brier score, and 10-bin top-class expected calibration error (ECE). Lower NLL, Brier, and ECE are better. Accuracy counts the top option.

All four labels matched the provisional references on 13/60 records. Against the [separate cached-score L1 evaluation](../anyjev-cached-l1-cv5-2026-09-24/evaluation.json), L2 improved follow-up accuracy from 13/60 to 43/60 and testimonial accuracy from 44/60 to 47/60, while sentiment fell from 37/60 to 33/60. Serious-concern accuracy rose from 34/60 to 36/60, but its NLL, Brier, and ECE worsened against L1. These are exploratory comparisons on the same 60 records, not an independent validation set or an isolated single-parameter effect.

The saved runtime was Python 3.12.12, PyTorch 2.10.0, Transformers 5.17.0, and NumPy 2.2.6 on macOS arm64. Model parameters were on MPS as BF16, with no quantization, batch size 4, and effective context 4,096. A [post-run host observation](hardware-observation.json) identified an Apple M4 Max with 128 GB memory; the saved predictions and terminal journal separately attest the actual tensor device and dtype. The smoke lasted 639.04 seconds and the full stage 627.80 seconds. The model was loaded separately for each stage, so their 1,266.84-second sum is not an uninterrupted 60-record run.

During native candidate-head fitting, NumPy emitted divide, overflow, and invalid-value warnings. All selected saved fold artifacts and 60 output records were checked recursively: no nonfinite numeric values remain, all class probabilities are finite and sum to one within 1e-6, and every selected artifact hash matches its prediction rows. The warning is retained as a numerical-stability limitation. Each head fitted on only 48 labels, below [AnyJev's stated 100–300 recommended L2 examples](https://github.com/nokia-applied-research/AnyJev/blob/3cd8c6fcd9e90fc04214575ade6779da1e3f3704/docs/levels.md); native inner cross-validation is ungrouped within the 48 outer-training records, although outer evaluation groups were preserved. The adapter mirrors this installed Qwen3/Transformers 5.17 no-cache block loop and is not a general adapter for other models or library versions. The proposed labels have no independent human adjudication, and no deployable head is claimed.
