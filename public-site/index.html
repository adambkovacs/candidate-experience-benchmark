Method and limits

Use this as a development comparison.

The 60 feedback records are synthetic. Read the source evidence and limitations before interpreting agreement as real-world accuracy.

What the labels mean

P0, P1 and P2 are prompt conditions. The same 60-record denominator applies to every score, including partial runs. The reference labels were drafted and reviewed by the same AI assistant; there was no independent human adjudication.

Request time adds recorded request durations. It is not the elapsed wall time of a concurrent batch. Local execution times describe this machine and workflow, not hosted speed rankings.

Cost separates billed API charges, estimates and unknown-charge ceilings. Subscription fees are not allocated per run. API-equivalent estimates are not billed charges.

Questions readers ask

Does valid / 60 mean the model was right?

No. Valid means the output could be scored. Correctness is agreement with the saved reference for each field.

Can I compare P0, P1 and P2 as an experiment?

You can inspect their saved outcomes together. Different surfaces, attempts and incomplete conditions limit causal claims. The page shows missing conditions rather than filling them in.

Why can a complete run have fewer than 60 valid outputs?

Completion means the run saved an outcome for each record. Some outputs still failed the response format or scoring rules.

Why are some prices unavailable?

Some services do not expose per-run charges. Missing charges are unavailable, not zero. An estimate or upper bound is labeled separately from an observed bill.

Can these scores choose a model for hiring decisions?

No. This small synthetic set tests feedback classification against provisional references. It does not measure deployment performance or candidate outcomes.
