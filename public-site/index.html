04 / METHOD

What these numbers can say.

This is a 60-record synthetic development set for recruitment feedback. Read the reference note below before interpreting agreement as accuracy.

01

The same denominator

Valid and correct sentiment are counted against all 60 development records. A partial run stays marked partial; missing records are never treated as correct.

02

Configuration matters

Read a result together with its model, reasoning effort, prompt, and execution surface. Differences in these controls limit direct comparisons.

03

Costs need context

Runtime, token counts, and API prices appear only when recorded. Subscription fees are not allocated per run. API-equivalent estimates are not billed charges.

QUESTIONS READERS ASK

Does "valid / 60" mean the model was right?

No. Valid means the response could be scored under the benchmark rules. Correct sentiment measures agreement with the reference label.

Why do some runs have no price?

Some surfaces expose token usage or billed API prices; others do not. Missing cost data is shown as unavailable, never as zero.

Can I use this to pick the best model overall?

No. The set is small and drawn from one task. The page is meant to help you inspect measured runs, including their setup and limits.

Why include partial results?

They show what happened during an incomplete run. They are hidden from the default comparison so a short run is not mistaken for a full 60-record outcome.
